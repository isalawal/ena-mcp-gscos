5. Architecture and Design Decisions

    

      
🔗

      

        
MCP stdio transport

        
Server uses stdio_server from the MCP Python SDK. AI agents connect via standard input/output — no HTTP server needed, making it lightweight and portable.

      

    

    

      
📋

      

        
Explicit tool schemas

        
Every tool has a typed inputSchema with required fields, defaults, and descriptions. The AI reads these schemas to know exactly what each tool accepts and returns.

      

    

    

      
⚡

      

        
In-memory caching with TTL

        
Responses cached for 300 seconds using URL+params as key. Eliminates redundant ENA calls — AI agents frequently repeat identical queries.

      

    

    

      
🚦

      

        
Token bucket rate limiter

        
Thread-safe rate limiter caps requests at 5/second. Automatically waits when limit is reached — transparent to the AI agent.

      

    

    

      
📦

      

        
Modular tool design

        
Each tool is independently defined with its own handler. Adding new endpoints requires only a new Tool() definition and elif block — the architecture scales cleanly.
